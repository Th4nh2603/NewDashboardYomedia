1. Tổng quan

Hệ thống chat AI: request/response qua tRPC (không streaming). Kiến trúc Supervisor → Router → Agents → Composer.

Lưu ý: Bubble UI (localStorage) ≠ ngữ cảnh LLM (server RAM). Refresh/xóa tin local không xóa short memory — dùng Xóa phiên hoặc rag.clearSession.

2. Luồng tổng thể

User → Chat.tsx → localStorage (bubble user)
     → readFileAsDataUrl → base64 (nếu có file/folder)
     → api.rag.query(question, provider, attachments, sessionId)
     → controllers/trpc/ragRouter (protected + assertChatAccess)
     → answerWithRag → runSupervisor(req)
     → guardrails → getShortMemory + mergeBuildDemoAttachments
     → resolveRoute → agents[] (1 hoặc nhiều)
     → runAgents (Promise.all — song song)
     → composeMultiResponse → appendShortMemoryTurn + logChatEvent
     → Response → bubble assistant (+ BuildDemoProgress nếu UI)

sessionId server = activeConversation.id client (vd. c-1717...).

2.4 Flow Chat RAG chi tiết (4 lớp controllers)

Sequence end-to-end

 1. User → Chat.tsx (nhập câu hỏi, optional file)
 2. Chat.tsx → localStorage (bubble user — chỉ UI)

 4. api.rag.query → POST /api/trpc/rag.query + Authorization Bearer
 5. trpc/context.ts → createContext → ctx.auth (Clerk)

 7. shared/schemas/rag.schema → Zod validate input

10. guardrails → shortMemory (key = email+role+sessionId)
11. resolveRoute → nếu rag: runRagAgent

Nhánh RAG — retrieval → LLM

question
  → load apps/server/rag/docs/*.md|txt|json (cache in-memory)
  → questionKeywords + scoreText trên từng doc
  → top 3 doc → extract snippet (~2400 chars/doc)
  → ghép contextPrompt
  → callProvider(provider, prompt, history từ shortMemory)
  → nếu primary fail → fallback openai ↔ gemini
  → AgentResult { answer, sources[], spans }

3. Pipeline server (runSupervisor)

Thứ tự cố định: Guardrails → Short memory → resolveRoute → runAgents → composeMultiResponse

3.1 Guardrails

  • Tin trống, > 1500 ký tự, từ nhạy cảm (password, api key, credit card, …)
  • Trả lỗi, không gọi AI — guardrails/index.ts

3.2 Short memory

  • Key: {email hoặc role:guest}::{sessionId hoặc default}
  • TTL 2h · tối đa 8 cặp turn
  • buildDemoAttachments — file pending đến khi upload thành công

3.3 Routing (resolveRoute)

4. Quyết định routing

User message
  ├─ Guardrail fail → lỗi (không gọi AI)
  ├─ resolveActionTool + rag candidate → rag agent (ưu tiên QA)
  ├─ resolveActionTool only → actions agent
  ├─ detectAgentCandidates > 1 → multi_intent (song song)
  ├─ Scoring 1 agent → sql / dashboard / rag
  ├─ LLM / rule intent
  │     ├─ knowledge_qa → rag
  │     ├─ sql_query → sql
  │     ├─ dashboard_insight → dashboard
  │     └─ free_chat → free_chat
  └─ composeMultiResponse + appendShortMemoryTurn + log
