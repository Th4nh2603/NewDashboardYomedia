Lệnh theo nhóm

  ┌────────────┬─────────────────────┬─────────────────────────────────────────────────────┐
  │    Nhóm    │        Lệnh         │                      Dùng khi                       │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │ Build      │ craft               │ Tạo feature mới (shape → code) end-to-end           │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ shape               │ Lên kế hoạch UX/UI trước khi code                   │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ init                │ Khởi tạo context (PRODUCT.md / DESIGN.md)           │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ document            │ Sinh DESIGN.md từ code hiện có                      │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ extract             │ Rút token/component ra design system                │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │ Đánh giá   │ critique            │ Review UX có chấm điểm heuristic                    │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ audit               │ Kiểm tra kỹ thuật (a11y, perf, responsive, AI-tell, |
  |            |                     | UI)                                                 │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │ Tinh chỉnh │ polish              │ Enhance ui                                          │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ bolder / quieter    │ Mạnh hơn / dịu lại                                  │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ distill             │ Lược bỏ rườm rà                                     │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ harden              │ Error/i18n/edge case                                │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ onboard             │ First-run, empty state                              │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │ Nâng cấp   │ animate             │ Thêm motion có chủ đích                             │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ colorize            │ Thêm màu cho UI đơn điệu                            │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ typeset             │ Sửa typography/hierarchy                            │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ layout              │ Sửa spacing/nhịp/bố cục                             │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ delight / overdrive │ Thêm cá tính / vượt giới hạn                        │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │ Fix        │ clarify             │ Sửa copy/label/error message                        │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ adapt               │ Responsive theo thiết bị                            │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │            │ optimize            │ Sửa hiệu năng UI                                    │
  ├────────────┼─────────────────────┼─────────────────────────────────────────────────────┤
  │ Iterate    │ live                │ Chọn element trên browser → sinh biến thể           │
  └────────────┴─────────────────────┴─────────────────────────────────────────────────────┘

  Quy trình điển hình

  ┌─────────────────────┬─────────────────────────────────┬────────────────────────────────────────────────┐
  │        Bước         │              Lệnh               │                    Kết quả                     │
  ├─────────────────────┼─────────────────────────────────┼────────────────────────────────────────────────┤
  │ 1. Thiết lập        │ init                            │ PRODUCT.md (chiến lược) + DESIGN.md (thị giác) │
  ├─────────────────────┼─────────────────────────────────┼────────────────────────────────────────────────┤
  │ 2. Soi              │ audit / critique                │ Báo cáo lỗi + điểm (P0–P3)                     │
  ├─────────────────────┼─────────────────────────────────┼────────────────────────────────────────────────┤
  │ 3. Sửa theo báo cáo │ quieter/typeset/clarify/layout… │ Áp đúng lệnh cho từng finding                  │
  ├─────────────────────┼─────────────────────────────────┼────────────────────────────────────────────────┤
  │ 4. Chốt             │ polish                          │ Pass cuối                                      │
  ├─────────────────────┼─────────────────────────────────┼────────────────────────────────────────────────┤
  │ 5. Đo lại           │ audit                           │ Xem điểm cải thiện                             │
  └─────────────────────┴─────────────────────────────────┴────────────────────────────────────────────────┘

  Cần nhớ

  ┌─────────────┬───────────────────────────────────────────────────────────────────────────────────────────┐
  │    Điểm     │                                         Chi tiết                                          │
  ├─────────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
  │ Context     │ Mọi lệnh đọc PRODUCT.md/DESIGN.md trước (đã có sẵn trong dự án này)                       │
  ├─────────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
  │ Quét slop   │ Tự bắt AI-tell: gradient text, eyebrow-mọi-section, side-stripe, hero-metric, card grid   │
  │             │ đồng phục, numbered scaffold                                                              │
  ├─────────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
  │ audit ≠ sửa │ audit/critique chỉ báo cáo; muốn sửa thì chạy lệnh tương ứng                              │
  ├─────────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
  │ Quản lý     │ pin <lệnh> tạo shortcut $<lệnh>; hooks on tự quét sau mỗi lần sửa UI                      │
  ├─────────────┼───────────────────────────────────────────────────────────────────────────────────────────┤
  │ Bản sắc dự  │ Đang dùng register brand, lệnh sẽ theo reference/brand.md                                 │
  │ án          │                                                                                           │
  └─────────────┴───────────────────────────────────────────────────────────────────────────────────────────┘
