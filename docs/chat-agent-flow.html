1. Tổng quan

Hệ thống chat AI: request/response qua tRPC (không streaming). Hai lớp bộ nhớ tách biệt:

LớpFileVai trò
Clientapps/web/components/Chat.tsxUI, localStorage, provider, file/folder
APIapi.rag.queryMutation có auth
ServeranswerWithRagGuardrails, tool/intent, RAG, LLM, short memory
Lưu ý: Bubble UI (localStorage) ≠ ngữ cảnh LLM (server RAM). Refresh/xóa tin local không xóa short memory — dùng Xóa phiên hoặc rag.clearSession.

2. Luồng tổng thể

User → Chat.tsx → localStorage (bubble user)
     → readFileAsDataUrl → base64 (nếu có file/folder)
     → api.rag.query(question, provider, attachments, sessionId)
     → ragRouter (protected) → answerWithRag
     → getShortMemory(email::sessionId)
     → guardrails → resolveActionTool → classify intent
     → [actions] runBuildDemoTool / executeTool
     → [knowledge_qa] RAG → LLM
     → [free_chat] LLM
     → appendShortMemoryTurn + logChatEvent
     → Response → bubble assistant (+ BuildDemoProgress nếu UI)

sessionId server = activeConversation.id client (vd. c-1717...).

3. Pipeline server (answerWithRag)

Thứ tự cố định: Guardrails → Short memory → Tool → Intent → Nhánh xử lý

3.1 Guardrails

  • Tin trống, > 1500 ký tự, từ nhạy cảm (password, api key, credit card, …)
  • Trả lỗi, không gọi AI — apps/server/src/lib/ai/guardrails/index.ts

3.2 Short memory

  • Key: {email hoặc role:guest}::{sessionId hoặc default}
  • TTL 2h (SHORT_MEMORY_TTL_MS) · tối đa 8 cặp turn
  • buildDemoAttachments — file pending đến khi upload thành công

3.3 Tool (ưu tiên cao nhất)

ToolTrigger
helphelp, hướng dẫn, trợ giúp
time_nowmấy giờ, time now, giờ hiện tại
build_demobuild/upload demo, sftp, tải lên, tạo demo…

Phiên Build Demo active (isBuildDemoSessionActive): file pending trên server; history đã bắt đầu demo; assistant hỏi brand/format + user trả lời tiếp → mọi turn route build_demo dù không lặp từ khóa.

3.4 Intent (khi không có tool)

  1. LLM classifier → knowledge_qa | free_chat (ưu tiên knowledge_qa khi mơ hồ)
  2. Fallback rule classifyUserIntent
  3. Có tool → actions, classifierSource: rule_tool

3.5 Nhánh & fallback

IntentXử lý
actionsexecuteTool / runBuildDemoTool
knowledge_qaScore apps/server/rag/docs → contextPrompt → LLM
free_chatLLM + system prompt

Provider lỗi → fallback OpenAI ↔ Gemini (fallbackUsed: true).

4. Quyết định routing

User message
  ├─ Guardrail fail → lỗi (không gọi AI)
  ├─ resolveActionTool → actions → tool
  ├─ LLM / rule intent
  │     ├─ knowledge_qa → RAG → LLM
  │     └─ free_chat → LLM
  └─ appendShortMemoryTurn + log

5. Build Demo

runBuildDemoTool
  → mergeBuildDemoAttachments(memoryKey)
  → invokeBuildDemoAgent (function build_demo)
       → message: hỏi thêm metadata
       → tool_call: brandId, productCateId, demoFormat, folderName?
  → resolveBuildDemoToolInput (rule fallback nếu cần)
  → executeBuildDemo
       → validate brand (admin = all)
       → SFTP /script/demo/{year}/{month}/...
       → Video: makeVastXml · HTML: buildDemoInlineImages
  → "Build Demo thành công" → clearBuildDemoAttachments

Response: buildDemoProcessing: true khi SFTP thực sự chạy.

5.1 Nhiều lượt

LượtUserServer
1File/foldermergeBuildDemoAttachments — giữ file
2Brand, format (text)Agent/rule trích metadata
3+Bổ sungHỏi thêm hoặc execute

5.2 Client — BuildDemoProgress

Thanh tiến độ giả lập khi shouldShowBuildDemoProgress: có file + brand trong corpus + hint format. Không phản ánh SFTP thật.

File: apps/web/lib/buildDemoChatProgress.ts

7. RAG

Index: .md, .txt, .json trong apps/server/rag/docs — score keyword → top 3 → snippet → LLM.

PDF trong rag/docs hiện không được index bởi knowledgeBase.
